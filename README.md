One smart-speaker mishearing apology in one line (132 characters): the speaker heard "water the plants" as "order more plants," so 43 ferns arrived — and the original plant, the whole reason for the command, is still dry and watched them all arrive. The program writes that single line to /output/entry.txt. Sixteen candidates were written for this entry and put through a strict external review against the judge's published brief (it must be an apology for a real mishear, funny with a sharp twist rather than a strained pun, fresh rather than a misheard song title or name, in the device's own voice, with no word doing no work); the review killed the bare sound-alike lines, the record-it-twice privacy loop as stock speaker satire, and the lockout line that needs the speaker to grow legs, and this line won its top-five tournament 4-0, keeping one tested revision — deleting "now" before the ferns, so the inventory lands cleaner.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```
